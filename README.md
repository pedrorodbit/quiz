# Quiz Perguntados - Gerador para Impressao

Gerador de paginas de perguntas e respostas estilo Perguntados, otimizado para impressao em folha A4.

## Formato

- A4 (210 x 297 mm)
- 6 questoes por folha (2 colunas x 3 linhas)
- Preto e branco, limpo para impressao
- Cada questao contem: categoria, pergunta, 4 alternativas, resposta e explicacao

## Categorias

- Arte e Cultura
- Astronomia
- Gastronomia
- Tecnologia

## Niveis de dificuldade

- Facil
- Medio
- Dificil

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Clique em **Nova Pagina** para sortear novas questoes
3. Clique em **Imprimir** ou `Ctrl+P` para imprimir

Nao ha dependencias externas ou servidor necessario.
